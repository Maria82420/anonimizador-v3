# 🛡️ Anonimizador Legal-Tech V3 (Privacy by Design)

Plataforma web autónoma de seudonimización, ofuscación y protección de datos personales y sensibles para escritos judiciales, contratos, documentos Word (.docx) y PDFs.

## ⚖️ Principios de Arquitectura & Cumplimiento Normativo
- **Privacidad Absoluta (Ley Argentina 25.326 & RGPD):** Procesamiento 100% *client-side* en la memoria RAM del usuario. Cero almacenamiento o transferencia a servidores externos.
- **Seguridad Endurecida (V3):** Sanitización contra DOM-XSS, mitigación de reemplazos colisionales con callbacks seguros y detección ampliada de CUILs/CUITs/DNIs.
- **Formatos Soportados:** PDF, DOCX, TXT, CSV, MD.
- **Seudonimización Defensiva y Reversibilidad:** Reemplazo tokenizado con preservación de capitalización original para restituir los datos tras el procesamiento en modelos de IA.
